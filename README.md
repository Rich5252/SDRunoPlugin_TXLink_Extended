This is the current version of the SDRUno plugin transmitter control GUI for my Arduino transmitter module based on AD9851 DDS.

I'm currently moving the TX module from an Arduino Nano to an ESP32-S3 to add SSB generation to the existing CW, FT8/4/2 and RTTY modes.

For details of TX modules see: https://github.com/Rich5252/SDR-Plugin_TXlink_WSJT-X (original project) https://github.com/Rich5252/TXlink4_ESP32_CW_DIGI_SSB_TX_AD9851 (new ESP32 TX module)
